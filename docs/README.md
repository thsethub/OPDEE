## 🔧 Ferramentas e Tecnologias

### Frontend Mobile
- **React Native** - Framework multiplataforma
- **Expo** - Plataforma de desenvolvimento
- **React Navigation** - Sistema de navegação

### Backend
- **Supabase** - Backend-as-a-Service
- **PostgreSQL** - Banco de dados
- **Realtime** - Atualizações em tempo real

### IoT/Hardware
- **MQTT** - Protocolo de comunicação
- **Paho MQTT** - Cliente JavaScript
- **Trancas Eletrônicas** - Hardware de controle

## 🤝 Como Contribuir

### Reportar Problemas
1. Verifique se o problema já foi reportado
2. Use templates adequados
3. Forneça informações detalhadas
4. Inclua logs e screenshots

### Melhorar Documentação
1. Identifique lacunas na documentação
2. Faça fork do repositório
3. Crie branch para suas alterações
4. Submeta Pull Request

### Contribuir com Código
1. Leia a [Arquitetura](ARCHITECTURE.md)
2. Configure o [ambiente](SETUP.md)
3. Siga padrões estabelecidos
4. Teste suas implementações
