# 📖 Manual do Usuário - OPDEE

## Introdução

O OPDEE é um aplicativo móvel desenvolvido para controlar o acesso aos laboratórios e ambientes do Departamento de Engenharia Elétrica da UFPE. Este manual explica como usar todas as funcionalidades do sistema.

## Primeiros Passos

### Instalação do Aplicativo

1. **Baixe o aplicativo** através do link fornecido pela administração
2. **Instale no dispositivo** seguindo as instruções padrão
3. **Abra o aplicativo** para começar o processo de cadastro

### Primeiro Acesso - Cadastro

#### Passo 1: Tela de Boas-vindas
- Ao abrir o aplicativo pela primeira vez, você verá a tela de boas-vindas
- Toque em **"Começar"** para iniciar o cadastro

#### Passo 2: Preencher Dados Pessoais
1. **Nome Completo**: Digite seu nome completo
2. **Email Institucional**: Use obrigatoriamente seu email @ufpe.br
3. **Selecionar Ambiente**: Escolha o laboratório que deseja acessar
4. **Tipo de Usuário**: Selecione seu perfil:
   - **Estudante**: Para alunos de graduação e pós-graduação
   - **Professor**: Para docentes do departamento
   - **Servidor**: Para funcionários técnico-administrativos
   - **Coordenador**: Para coordenadores de curso/programa
   - **Terceirizado**: Para prestadores de serviço autorizados

#### Passo 3: Enviar Solicitação
- Revise suas informações
- Toque em **"Solicitar Acesso"**
- Aguarde a mensagem de confirmação
- Seu pedido será enviado para aprovação

### Aguardando Aprovação

Após o cadastro:
- Seu acesso precisa ser **aprovado por um administrador**
- Você receberá notificação quando for aprovado
- O processo pode levar **até 48 horas úteis**

## Usando o Aplicativo

### Autenticação Automática

O OPDEE usa o **ID único do seu dispositivo** para autenticação:
- **Não precisa de senha**: O login é automático
- **Segurança**: Cada dispositivo é identificado unicamente
- **Conveniência**: Acesso rápido sempre que abrir o app

### Tela Principal (Ambientes)

Após aprovação, você verá:

#### Lista de Ambientes
- **Ambientes Disponíveis**: Laboratórios que você pode acessar
- **Status de Acesso**: Indicação visual se está ativo
- **Prioridade**: Coordenadores aparecem no topo da lista

#### Informações por Ambiente
- **Nome do Laboratório**: Ex: "Laboratório de Circuitos"
- **Seu Tipo de Usuário**: Perfil associado a este ambiente
- **Status**: Ativo (pode acessar) ou Inativo (sem permissão)

### Abrindo um Laboratório

#### Passo a Passo
1. **Selecione o ambiente** na lista principal
2. **Confirme sua intenção** na janela de confirmação
3. **Aguarde o comando** ser enviado para a tranca
4. **Verifique o resultado** - sucesso ou erro

#### Mensagens do Sistema
- ✅ **"Mensagem enviada com sucesso"**: Comando executado
- ❌ **"Falha ao enviar mensagem"**: Erro na comunicação
- ⚠️ **"Acesso negado"**: Sem permissão ou offline

### Solicitando Novos Acessos

#### Quando Usar
- Precisa acessar um **novo laboratório**
- Mudou de **função/categoria** no departamento
- Perdeu acesso a um **ambiente específico**

#### Como Fazer
1. Na tela principal, toque **"Solicitar acesso"**
2. **Selecione o novo ambiente** da lista
3. **Confirme seu tipo de usuário** (pode ter mudado)
4. **Envie a solicitação**
5. **Aguarde aprovação** da administração

### Navegação no App

#### Telas Principais
- **Welcome**: Tela de boas-vindas para novos usuários
- **Ambientes**: Lista de laboratórios acessíveis (tela principal)
- **Solicitar Acesso**: Para pedir acesso a novos ambientes
- **Configurações**: Apenas para administradores

#### Botões e Ações
- **Acessar**: Entra na lista de ambientes
- **Solicitar acesso**: Nova solicitação de ambiente
- **Voltar**: Retorna à tela anterior
- **Tocar no ambiente**: Abre o laboratório selecionado

## Perfis de Usuário

### 🎓 Estudante
**Características:**
- Acesso básico aos laboratórios
- Pode solicitar acesso a labs relacionados aos seus cursos
- Acesso sujeito a horários de funcionamento
- Precisa de aprovação para cada novo ambiente

**Ambientes Típicos:**
- Laboratórios de aulas práticas
- Salas de estudo com equipamentos específicos
- Laboratórios de pesquisa (sob supervisão)

### 👨‍🏫 Professor
**Características:**
- Acesso amplo aos laboratórios
- Pode acessar fora do horário comercial
- Prioridade em solicitações de acesso
- Pode supervisionar acesso de estudantes

**Ambientes Típicos:**
- Todos os laboratórios didáticos
- Laboratórios de pesquisa da área
- Salas de professores
- Ambientes administrativos relacionados

### 👷 Servidor
**Características:**
- Acesso a áreas técnicas e administrativas
- Permissões de manutenção e suporte
- Acesso a laboratórios para fins técnicos
- Horários flexíveis de acesso

**Ambientes Típicos:**
- Salas técnicas
- Áreas de equipamentos
- Laboratórios (para manutenção)
- Áreas administrativas

### 🎯 Coordenador
**Características:**
- **Acesso prioritário** a todos os ambientes
- **Aparece no topo** da lista de ambientes
- Pode ter **funções administrativas** especiais
- Acesso irrestrito de horários

**Ambientes Típicos:**
- Todos os laboratórios do departamento
- Salas administrativas
- Áreas de coordenação
- Ambientes especiais

### 🔧 Terceirizado
**Características:**
- Acesso limitado e temporário
- Específico para funções contratadas
- Supervisionado por servidores
- Validade determinada

**Ambientes Típicos:**
- Áreas específicas do contrato
- Locais de manutenção autorizada
- Laboratórios sob supervisão

## Situações Especiais

### Primeiro Login após Aprovação

1. **Abra o aplicativo**
2. **Será automaticamente reconhecido** pelo sistema
3. **Verá mensagem de boas-vindas** com seu nome
4. **Acesse a lista de ambientes** disponíveis

### Mudança de Dispositivo

Se trocar de celular/tablet:
1. **Instale o app** no novo dispositivo
2. **Cadastre-se novamente** com os mesmos dados
3. **Aguarde nova aprovação** (ID do dispositivo mudou)
4. **Informe a administração** sobre a mudança

### Problemas de Conectividade

#### Sem Internet
- ❌ **Não é possível acessar** ambientes
- ❌ **Lista não atualiza**
- ⚠️ **Mensagem de erro** será exibida

#### Soluções:
1. **Verifique sua conexão** Wi-Fi ou dados móveis
2. **Tente novamente** após conectar
3. **Reinicie o aplicativo** se necessário

### Acesso Negado

#### Possíveis Causas:
- **Permissão revogada** pela administração
- **Ambiente desativado** temporariamente
- **Problema técnico** no sistema
- **Tentativa fora** do horário permitido

#### O que Fazer:
1. **Verifique se tem** permissão para este ambiente
2. **Tente outros** ambientes disponíveis
3. **Entre em contato** com a administração
4. **Aguarde e tente** novamente mais tarde

### Erro na Tranca Eletrônica

Se a tranca não abrir:
1. **Tente novamente** após alguns segundos
2. **Verifique se** a mensagem foi enviada com sucesso
3. **Procure ajuda** de um técnico próximo
4. **Reporte o problema** à administração

## Dicas de Uso

### Boas Práticas

#### Segurança
- 🔐 **Não empreste** seu dispositivo para outros usuários
- 🔐 **Não compartilhe** acesso a ambientes
- 🔐 **Feche sempre** os laboratórios após uso
- 🔐 **Reporte** qualquer problema de segurança

#### Eficiência
- ⚡ **Mantenha o app** atualizado
- ⚡ **Verifique conexão** antes de tentar acesso
- ⚡ **Feche e reabra** o app se estiver lento
- ⚡ **Use Wi-Fi** quando disponível para melhor performance

#### Etiqueta
- 🤝 **Seja pontual** - libere o ambiente no horário
- 🤝 **Mantenha organizado** o laboratório
- 🤝 **Respeite** equipamentos e instalações
- 🤝 **Ajude** colegas com dificuldades

### Otimização da Experiência

#### Para Melhor Performance
1. **Feche outros apps** que consomem muita rede
2. **Use Wi-Fi** preferencialmente
3. **Mantenha o app** sempre na versão mais recente
4. **Reinicie** o dispositivo ocasionalmente

#### Para Economizar Bateria
1. **Feche o app** quando não estiver usando
2. **Diminua o brilho** da tela se necessário
3. **Use modo avião** quando não precisar de rede
4. **Carregue o dispositivo** antes de usar

## Solução de Problemas

### Problemas Comuns

#### "App não abre"
**Soluções:**
1. Reinicie o dispositivo
2. Reinstale o aplicativo
3. Verifique espaço de armazenamento
4. Atualize o sistema operacional

#### "Lista vazia de ambientes"
**Possíveis Causas:**
- Ainda não foi aprovado
- Sem conexão com internet
- Problema no servidor

**Soluções:**
1. Verifique conexão
2. Aguarde aprovação
3. Feche e reabra o app
4. Contate administração

#### "Erro ao enviar comando"
**Soluções:**
1. Verifique conexão
2. Tente novamente
3. Reinicie o app
4. Reporte o problema

#### "Não consigo me cadastrar"
**Verificações:**
- Email termina com @ufpe.br?
- Todos os campos preenchidos?
- Conexão com internet ok?
- Já existe cadastro neste dispositivo?

### Quando Contactar o Suporte

#### Situações que Requerem Suporte:
- ❌ App não funciona após múltiplas tentativas
- ❌ Acesso negado sem explicação aparente
- ❌ Problemas persistentes de conectividade
- ❌ Necessidade de alterar dados cadastrais
- ❌ Mudança de perfil de usuário
- ❌ Perda/troca de dispositivo

#### Informações para Fornecer:
1. **Seu nome completo**
2. **Email cadastrado**
3. **Tipo de dispositivo** (Android/iOS)
4. **Descrição detalhada** do problema
5. **Passos** que levaram ao erro
6. **Horário** em que ocorreu
